# Machine Learning Training Subsystem

This directory contains the Python training infrastructure for training and exporting custom bug root cause prediction models.

## Structure
- `data/`: Raw and preprocessed bug datasets.
- `src/`: Data ingestion, preprocessing, training, and evaluation scripts.
- `artifacts/`: Exported model weights, vocabulary, and ONNX pipelines.
- `requirements.txt`: Python package requirements (scikit-learn, pandas, numpy).
